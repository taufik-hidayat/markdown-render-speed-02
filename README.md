A faster drop-in replacement for marked 18.1.3, written from scratch: `parse.js` renders exactly the HTML marked renders with its default options (GFM on, breaks off, pedantic off), and `main.ts` is the driver the harness runs — it reads every case from `/input/cases.json`, renders each with `parse`, and writes `/output/html.json`.

## Run it

```sh
node main.ts
```
